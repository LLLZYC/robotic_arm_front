# 🦾 机械臂控制系统 (简化版)

## 功能概述

这是简化后的机械臂控制界面，只保留核心功能：

### ✅ 保留的功能

1. **机械臂状态监控**
   - 连接状态显示
   - 运行模式显示  
   - 当前角度显示

2. **Demo模式控制**
   - Demo模式开关
   - 线性插入服务调用按钮
   - 服务调用结果显示

### ❌ 移除的功能

- 预设动作按钮
- 手动角度控制
- 操作日志输出
- 复杂的控制面板

## 使用方法

### 1. 访问界面
打开浏览器访问: http://localhost:3000

点击 "🦾 机械臂控制" 标签页

### 2. 查看状态
页面顶部会显示：
- 🏠 **DEMO** 标记
- **机械臂状态** 卡片，包含：
  - 连接状态：已连接/未连接
  - 运行模式：待机/就绪/执行中
  - 当前角度：0°-180°范围

### 3. Demo控制
在 **Demo控制** 区域：

- **启动Demo** 按钮：激活Demo模式
- **🚀 执行线性插入服务** 按钮：调用ROS2服务

### 4. 服务调用
当Demo模式激活后：

1. 点击 "🚀 执行线性插入服务"
2. 系统会调用：`ros2 service call /run_linear_insert std_srvs/srv/Trigger {}`
3. 底部显示服务调用结果：
   - 状态：成功/失败
   - 消息：详细结果

## 技术实现

### 前端
- Vue 3 + Composition API
- 响应式状态管理
- 现代化UI设计

### 后端API
- Express.js 服务器
- ROS2服务代理

### 服务端点
- `POST /api/ros2/service/run_linear_insert`
- 调用实际的ROS2服务
