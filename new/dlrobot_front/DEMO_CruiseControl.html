🚗 DLRobot 巡航控制功能演示

📍

巡航点管理

可视化编辑、添加、删除巡航点，支持精确的坐标和朝向设置，实时保存到后端配置。

🎮

手动控制

通过方向键实时控制机器人移动，可调节速度和转向速度，支持前进、后退、左转、右转。

⏯️

巡航控制

一键开始、停止、恢复巡航任务，实时显示巡航状态和当前目标点。

📊

状态监控

实时显示机器人位置、巡航状态、目标点信息，与后端系统完全同步。

🚀 快速开始

  1. 启动前端应用：npm run dev
  2. 启动后端 autocontrol 节点：roslaunch dlrobot_autocontrol autocontrol.launch
  3. 在浏览器中打开 http://localhost:3002
  4. 点击 "🚗 巡航控制" 标签页
  5. 确保 MQTT 和 REST API 连接正常

🎯 巡航点操作演示

添加巡航点

  1. 点击 "➕ 添加巡航点" 按钮
  2. 在弹出的对话框中填写：
    名称: waypoint_entrance
    X 坐标: 2.5
    Y 坐标: 1.5
    YAW 角度: 1.57 (90度)
    到达前等待: 2.0秒
    到达后等待: 3.0秒
  3. 点击 "保存" 完成添加
  4. 点击 "💾 保存巡航点" 将配置保存到后端

前往特定巡航点

在巡航点列表中，点击目标巡航点旁的 "🎯" 按钮，机器人将立即导航到该位置。

编辑和删除

  • 点击 "✏️" 按钮编辑现有巡航点
  • 点击 "🗑️" 按钮删除不需要的巡航点

🎮 手动控制演示

⚠️ 安全提示

使用手动控制时，请确保机器人周围有足够的空间，并适当控制速度以避免碰撞。

基本操作

  • 前进: 按住 "⬆️" 按钮
  • 后退: 按住 "⬇️" 按钮
  • 左转: 按住 "⬅️" 按钮
  • 右转: 按住 "➡️" 按钮

速度调节

  • 线性速度: 0.1 - 1.0 m/s (控制前进后退速度)
  • 角速度: 0.1 - 1.0 rad/s (控制转向速度)

松开按钮后，机器人会自动停止移动。

🔄 巡航任务控制

巡航状态

  • 待机: 机器人空闲，等待指令
  • 巡航中: 正在按巡航点序列导航
  • 已停止: 巡航任务被暂停

控制操作

  • ▶️ 开始巡航: 开始或恢复巡航任务
  • ⏹️ 停止巡航: 立即停止当前巡航任务
  • ⏯️ 恢复巡航: 从停止状态恢复巡航

🔌 API 接口说明

巡航点管理

GET /api/navigation/default_goals
获取当前配置的所有巡航点
POST /api/navigation/default_goals
更新巡航点配置
{ "goals": [ { "name": "waypoint_a", "position": {"x": 1.0, "y": 0.0, "z": 0.0}, "orientation": {"yaw": 0.0}, "wait_before": 2.0, "wait_after": 3.0 } ] }

巡航控制

POST /api/navigation/hold
停止巡航任务
POST /api/navigation/resume
恢复巡航任务

手动控制

通过 MQTT 发布到 /cmd_vel 话题：

{ "linear": {"x": 0.3, "y": 0, "z": 0}, "angular": {"x": 0, "y": 0, "z": 0.5} }

🛠️ 技术实现

前端架构

  • Vue 3 + Composition API: 现代化的响应式界面
  • Pinia Store: 集中状态管理
  • MQTT.js: 实时通信和状态同步
  • Axios: REST API 调用

后端集成

  • dlrobot_autocontrol: ROS 节点提供巡航控制服务
  • REST API: 端口 17863，提供 HTTP 接口
  • MQTT Broker: 端口 9001，处理实时消息
  • move_base: 底层导航系统

数据流

  1. 用户界面操作 → REST API 请求
  2. 后端处理 → 更新巡航配置
  3. 状态变化 → MQTT 消息推送
  4. 前端接收 → 实时界面更新

💡 使用建议

  • 在开始巡航前，确保所有巡航点坐标正确
  • 使用手动控制进行精确位置调整
  • 定期保存巡航点配置以防丢失
  • 监控巡航状态，及时处理异常情况
